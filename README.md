# FoxFire – Custom FOC Motor Driver

**FoxFire** is a high-performance **Field-Oriented Control (FOC)** motor driver designed for precise, efficient, and reliable control of BLDC and PMSM motors. Powered by the **STM32G431CBU6** and integrated with advanced power electronics like the **DRV8353FS**, this board is ideal for robotics, electric vehicles, and industrial automation projects where optimal torque and speed control are essential.

---

## Features

- STM32G4 Series MCU (STM32G431CBU6) for high-speed processing and advanced motor control algorithms  
- DRV8353FS 3-phase gate driver with fault protection and high efficiency  
- Support for Field-Oriented Control (FOC) and sinusoidal commutation  
- Integrated CAN FD communication for real-time control and diagnostics  
- High-current MOSFETs (CSD18540Q5B) for robust power delivery  
- Precise current sensing and protection circuits  
- Dual supply rails: 3.3V logic, 5V auxiliary, and motor drive voltage from VM input  
- SWD interface for debugging and firmware updates  
- Multiple connectors for encoder feedback, UART, CAN bus, and external power  
- Safety features: Overcurrent, overtemperature, and undervoltage protection  

---

## Included Components

- STM32G431CBU6 MCU  
- DRV8353FS 3-phase motor driver  
- CSD18540Q5B MOSFETs  
- CAN transceiver (TJA1462AT)  
- Voltage regulators (AP2112K-3.3TRG1, TPS54302DDCR)  
- Power capacitors, inductors, and protection resistors  
- Debug interface (SWD, UART) and communication ports (CAN FD, I2C)
